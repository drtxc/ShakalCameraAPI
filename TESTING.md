# Тестирование ШакалCamera

## Юнит-тесты

### PresetsTest
- `presets contain exactly levels 1 through 10 and 12` — проверяет, что уровни ровно {1..10, 12}
- `all preset fields are present` — проверяет все поля Preset
- `video bitrate calculation is logarithmic` — проверяет расчёт битрейта

### CpuPipelineTest (на устройстве)
- Каждый уровень на Bitmap 1920×1080 отдаёт результат без исключений
- Результат имеет ожидаемые размеры (1280 по длинной стороне)

## Ручной чек-лист

### Превью
- [ ] Превью ≥25 fps на уровне 1 при хорошем освещении
- [ ] Просадка fps в темноте на уровнях 1 и 8 (до fpsLowLight)
- [ ] Смена уровня мгновенная, без пересоздания камеры
- [ ] Фризы кадра работают на уровне 10 (случайные остановки 0.3–1 с)
- [ ] Rolling shutter «желе» работает на уровне 8 при движении камеры
- [ ] Переключение фронт/тыл без краша
- [ ] Работа в портретной и альбомной ориентации

### Фото
- [ ] Фото визуально совпадает с превью (палитра, шум, блоки)
- [ ] Файл сохраняется в `Pictures/ShakalCamera/`
- [ ] Имя файла: `shakal_<level>_<timestamp>.jpg`
- [ ] Фото открывается в стандартной галерее
- [ ] Фото отправляется в мессенджерах (Telegram, WhatsApp)
- [ ] Нет EXIF с геолокацией

### Видео
- [ ] Видео записывается при удержании кнопки
- [ ] Видео останавливается при отпускании
- [ ] Видео играется в стандартном плеере
- [ ] Видео отправляется и воспроизводится в Telegram
- [ ] Звук записывается (для уровней 1–6: 22050 Гц, 7–12: 8000 Гц)
- [ ] Лимит записи — 3 минуты (автоостановка)
- [ ] Файл сохраняется в `Movies/ShakalCamera/`

### UI
- [ ] Запоминание последнего уровня после перезапуска
- [ ] Запоминание выбора камеры (фронт/тыл) после перезапуска
- [ ] Тёмная тема
- [ ] Крупные элементы управления
- [ ] Миниатюра последнего снимка открывает галерею
- [ ] Диалог «О программе» с текстом «Делаем ваше фото прекрасным»
- [ ] Слайдер показывает «X/10 шакалов»

### Совместимость
- [ ] Работает на Android 8.0 (API 26)
- [ ] Работает на Android 15 (API 35)
- [ ] Нет крашей при отсутствии камеры
- [ ] Нет крашей при отказе в разрешениях
